# SIMPLE-EXPENCE-TRACKER
This Expense Tracker is a simple, easy-to-use Python program that helps you manage and record your daily spending. Instead of using a complicated graphical interface, it runs directly in your terminal using a clear, number-based menu.
Here is exactly what it does:

Records New Expenses: You can easily log a new purchase by entering the date, the category (like Food, Travel, or Utilities), the cost, and a quick note. The program saves this data safely into a CSV file, which acts just like a basic spreadsheet.

Shows Your Spending History: You can choose to view a complete list of all your recorded expenses at any time. The program reads your file, displays each item neatly, and automatically calculates the total amount of money you have spent.

Summarizes by Category: It groups your expenses together to show you a breakdown of where your money is going. For example, it will tell you exactly how much you spent on "Food" versus "Travel."

One of its best features is its built-in safety net: if you accidentally type letters instead of a number when entering a price, the program gently asks you to try again instead of crashing!
